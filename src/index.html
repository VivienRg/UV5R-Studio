Program the radio

  1. Plug the programming cable into the computer, then into the radio. Push it in until it clicks twice.
  2. Turn the radio on. Volume up a little helps some cables.
  3. Read from radio first. A backup is saved automatically.
  4. Edit channels, then Write to radio. Settings menus stay as they are; only channels and names are written.

    How it works
    
          
    Received speech is turned into text on this computer with Whisper, then translated into your language. Morse and packet text are decoded the same way.
    
          
    When you send, text can be translated into the radio language first, then spoken with a system voice, keyed as Morse, or sent as a packet message.

    Language
