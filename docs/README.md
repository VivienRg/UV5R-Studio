# UV5R Studio documentation

This directory contains user, developer, build, signing, and safety documentation for UV5R Studio.

- [Development](development.md) — run the application and tests from source.
- [Building releases](building.md) — create platform packages locally and in GitHub Actions.
- [Signing](signing.md) — configure Apple signing and the Windows self-signed certificate.
- [Radio safety](radio-safety.md) — operating responsibilities and transmit safeguards.
- [Contributing](../CONTRIBUTING.md) — issue and pull-request process.

For a product overview and quick start, return to the [project README](../README.md).
