# Radio safety and operator responsibility

UV5R Studio starts in receive-only mode. Certified mode requires licence acknowledgement and a valid application signature before transmit features become available.

The operator remains responsible for:

- Holding the licence required in the operating jurisdiction.
- Using only permitted frequencies, modes, bandwidths, and power levels.
- Identifying transmissions as required.
- Avoiding emergency, public-safety, aviation, marine, and other protected services.
- Confirming channel data before writing it to a radio.
- Using suitable isolation, audio levels, and keying hardware.

Read the radio before writing changes so a known-good backup exists. A software safeguard cannot determine every local rule or prevent every incorrect hardware configuration.
